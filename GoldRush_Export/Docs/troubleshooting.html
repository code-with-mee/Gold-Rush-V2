GOLD RUSH · Help

Troubleshooting

Something does not work? Find the symptom below. Each answer links to the step that fixes it. Every phase also has its own “Common problems” table at the end.

Try these first
  • Look at the Console (Window → General → Console). The first red error is usually the real cause. Double-click it to open the script at that line.
  • Stop Play mode before you change anything, and wait for Unity to finish compiling (the spinner in the bottom-right corner).
  • Many objects (the Player, the camera, coins, monsters, orbs) exist only in Play mode. The GameManager makes them from the markers when the level starts. Look for them while the game runs.
  • Broke something in a “Try it” step? Import the phase package again into a new, empty project (or delete Assets/GoldRush first) and add the scenes to the Scene List.

Project and import

Everything is pink

The project is not URP. Make a new project with the Universal 3D template, and do not delete the Settings folder (Phase 0, step 2, step 3).

The template Universal 3D is not in the list

Scroll down in Unity Hub, or click the download icon next to it. Use Unity 6000.6.10f1 or newer (Phase 0, step 2).

I cannot find Package Management in the Window menu

In some Unity 6 versions it is Window → Package Manager directly (Phase 0, step 4).

Red errors about Unity.AI.Navigation right after the import

Install AI Navigation in the Package Manager (Phase 0, step 4). The errors go away by themselves.

“You are trying to read Input using the UnityEngine.Input class…”

Set Edit → Project Settings → Player → Other Settings → Active Input Handling to Both and let Unity restart (Phase 0, step 5).

I chose Active Input Handling = Both, but nothing happened

Unity must restart. Close Unity yourself and open the project again from Unity Hub (Phase 0, step 5).

After the import I have files like GoldRushMenu 1.cs or FX 1.cs

You imported a package into a project that already had the files. Every package has all the scripts. Make a new, empty project, or delete the folder Assets/GoldRush before you import (Phase 1, step 2).

I opened the scene, but PLAY (or MENU, NEXT) cannot load a scene

A package does not bring the Scene List. After every import, add the scenes to File → Build Profiles → Scene List, with MainMenu first (Phase 3, step 2, Phase 10, step 1).

A kit piece floats above the floor or sinks into it

Set its Position Y to 0. The pivot of every kit piece is at the bottom (Phase 0, check 3).

Scripts and compile errors

Red errors after I changed a script in “Try it”

Look at the first error: it names the file and the line. Often a missing ;, f after a number (8f) or ". Press Ctrl+Z / Cmd+Z in your code editor, or import the phase package again.

“The namespace 'GoldRush' already contains a definition for …”

A script exists twice, for example Data.cs and Data 1.cs. You imported into a project that already had the scripts. Delete the copy with the number, or start again in a new, empty project.

I can't add a component, or my change has no effect

Unity can not add components or run new code while there are red errors in the Console. Fix them first.

My Inspector changes disappeared when I stopped Play

Unity always undoes changes made in Play mode. Write the good value down, stop Play, and type it again. Objects made by code (Player, camera, monsters) are gone after Play anyway: change the script value instead (Phase 4, step 6).

Main menu and UI

Console: “GoldRushAssets missing”

The asset must be called exactly GoldRushAssets and be inside Assets/GoldRush/Resources. Do not move or rename files in Resources. Import the package again (Phase 4, check 6).

Buttons do nothing when I click

Are you in Play mode and clicking in the Game view? The scene needs its EventSystem (Phase 1, check 1).

Console: “Unknown menu action”

A typo in the Action field of Menu Action. Use exactly play, levels, shop, back, settings or closeSettings (capital S) (Phase 1, check 7, Phase 2, check 5).

UI looks tiny or huge

Game view: Full HD (1920x1080). Canvas Scaler: Scale With Screen Size, 1920 × 1080, Match 0.5 (Phase 1, check 5).

The menu scene is flat or too bright in the editor

Normal: the script sets the night mood, fog and glow in Play mode (Phase 1, step 4).

The level cards, the tabs or the shop items are empty in Edit mode

Normal. Cards, Tabs and Grid are empty boxes: the script fills them when a screen opens in Play mode (Phase 2, check 1).

I cannot see the Settings dialog in the Scene view

It is inactive until you click the gear. Tick it to look at it, and untick it again before Play (Phase 2, check 4).

PLAY or a level card: the screen goes black and the Console says the scene “couldn't be loaded”

Normal in phases 1–2: there is no level yet. Level1 comes in Phase 3, Levels 2–4 and the Daily Rush in Phase 10.

Buying always fails

You have 0 gold. You win gold in the levels. For a test, give yourself gold in Data.cs (Phase 2, step 6).

I changed gold = 500 in Data.cs, but I still have 0

The old save is still there. Stop Play mode → Edit → Clear All PlayerPrefs (Phase 2, step 7).

I want to start over with no gold and only Level 1 unlocked

Stop Play mode, then Edit → Clear All PlayerPrefs.

The level and the Scene List

PLAY does nothing: “Scene 'Level1' couldn't be loaded because it has not been added to the build settings”

Add Scenes/Level1 to File → Build Profiles → Scene List. The name must be exactly Level1, no space (Phase 3, step 2).

The build (or Play) starts in Level1, not in the menu

In the Scene List, MainMenu must be number 0. Drag it to the top (Phase 3, check 8).

The level is dark and grey, with no sunset sky

Window → Rendering → Lighting → Environment: Skybox Material = GR_SunsetSky, Sun Source = Sun (Phase 3, step 4). From Phase 4 on, the game sets the sky, fog and sun itself at Play.

Glow materials do not glow

Normal in Edit mode. They shine in Play mode, when EnvironmentSetup adds bloom.

I changed a kit prefab by mistake (Apply All)

Try Edit → Undo, or import the package again. Never click Overrides → Apply All on a kit piece (Phase 3, step 1).

I cannot leave Prefab Mode

Click the < arrow at the top left of the Hierarchy, or double-click the scene file.

I cannot see the markers

Turn on Gizmos in the Scene view toolbar. Then CoinSpots show a gold ball, PlayerSpawn a blue arrow, monsters a wire box and power-ups a wire ball (Phase 5, check 3).

Player and camera

I cannot find the Player or the Main Camera in the Hierarchy

Normal. The GameManager makes them when you press Play, at PlayerSpawn (Phase 4, check 1).

Keys do nothing

Wait for GO!, then click inside the Game view (Phase 4, step 5).

The hero is invisible, or stands in a T-pose

Open Resources/GoldRushAssets → Hero: Model and Controller must be filled (Phase 4, check 6). Import the package again if they are empty.

The hero's feet slide, or he is tiny or giant

Check the Hero values in GoldRushAssets: Height 1.35, Walk Speed 0.587, Run Speed 0.836 (Phase 4, check 6).

The mouse cursor disappeared

The game locks it so the mouse can turn the camera. Press Esc to get it back. Click in the Game view to lock it again.

The mouse does not turn the camera

Click inside the Game view so the cursor locks. You can also turn with Q / E (Phase 4, step 5).

The camera looks through walls

The wall has no collider. Kit walls have one: do not remove it.

Coins, gate, win and lose

I do not see any Coin in the Hierarchy

Normal. The coins exist only in Play mode, under Dynamic (runtime) (Phase 5, check 5).

Warning: “This level has no CoinSpot objects”

Normal in Phase 4 (the coins come in Phase 5). Later: the CoinSpots need the Coin Spot component and must be inside the level root (Phase 5, check 2).

No coin sound. Console: “[AudioFX] Unknown sound id: coin”

The Sounds list in GoldRushAssets is empty, or coin.wav is missing. The file name is the sound id (Phase 5, check 4).

All coins collected, but the gate does not open

The gate must be inside the level root and have the Exit Gate component with Door filled (Phase 6, check 2).

The gate opens, but the strips stay red

Strips or Green Strip is empty on Exit Gate (Phase 6, check 2).

I stand at the gate and nothing happens

Collect all coins first. The gate Rotation must be 0, 0, 0: the win point is on its -Z side (Phase 6, step 4).

The hero walks out through the open gate

GateBlocker is missing or has no Box Collider (Phase 6, check 4).

After the win: “Scene 'MainMenu' couldn't be loaded”

Add MainMenu to the Scene List, at number 0 (Phase 6, step 2).

Monsters

Error: “The type or namespace name 'Unity.AI.Navigation' could not be found”

Install AI Navigation in the Package Manager (Phase 0, step 4).

I cannot find the monsters in the Hierarchy

Normal. They exist only in Play mode, under Dynamic (runtime) (Phase 7, check 6).

Monsters stand still: “SetDestination” can only be called on an active agent…

The marker is on a block or outside the walls. Move it onto free floor. Static must keep its NavMesh Surface (Phase 7, check 1).

Monsters walk through walls

The wall has no collider, or it is not inside Static. The NavMesh is built again each time the level starts (Phase 7, check 1).

A monster is invisible

Fill Model and Controller for that monster in GoldRushAssets (Phase 7, check 4).

Monsters never see me

Something with a collider is in the way. In GHOST mode they can't see you on purpose.

Monsters got faster after I took the last coin

That is on purpose: after the last coin every monster gets 10 % faster for the race to the exit (Phase 7, step 4).

Power-ups and effects

There is no orb in Play mode

The marker must be inside the level root (in Gameplay/PowerUps) and have a Power Up Spot component (Phase 8, check 2).

An orb that I cannot pick up

You dragged a Prefabs/Gameplay/PowerUp_* orb into the level on its own. The game only finds power-ups inside a Power Up Spot. Use a marker from Prefabs/Markers instead (Phase 8, check 4).

I walk into the orb and nothing happens

Walk right through the middle (closer than 1.6 m). The marker must stand on the floor (Y about 0) (Phase 8, step 3).

Particles are pink squares

Open GoldRushAssets and set Particle = GR_Particle (Phase 8, check 6).

Monsters still see me in GHOST mode

GHOST lasts only 6 s. When the power-up bar in the HUD is empty, the power is off.

HUD and dialogs

A dialog button does nothing

It needs a Game Action (not Menu Action) with one of these words: pause, resume, retry, menu, next. “Unknown game action” in the Console means a spelling mistake. The scene also needs its EventSystem (Phase 9, check 5).

Everything appears twice in Play mode

The Hud field of Game UI is empty, so it builds a second UI in code. Import the package again (Phase 9, check 2).

NullReferenceException in ShowPause, ShowWin or ShowLose

You deleted or renamed a part that a Game UI field points to. Import the package again (Phase 9, check 2).

I click on the HUD, but the camera turns

While you play, the mouse is locked. Press Esc first to free it.

NEXT: “Scene 'Level2' couldn't be loaded”

Normal in phase 9. Levels 2–4 come in Phase 10. There, add all six scenes to the Scene List (Phase 10, step 1).

Day/night, touch, sound and build

The sky turns dark, but the floor and walls do not

The palette must be at Assets/GoldRush/Resources/DayNightPalette.asset (exact name). The level root needs a Day Night Tint (Phase 10, check 2).

After Play, a material stays dark blue

Something changed the material file itself. Set its colour back by hand in the Materials folder.

A lamp shines during the day

Its light needs a Night Light component (Phase 10, check 3).

Touch does nothing in the Simulator

Click on the phone screen, not outside it. Check Active Input Handling = Both and the Joystick field of GameUI (Phase 10, check 5).

No sound or no music

  • Check Mute Audio at the top of the Game view.
  • Check MUSIC and SOUND in the game's Settings or the PAUSE dialog. They are saved, so they stay off next time (Phase 2, check 4).
  • [AudioFX] Unknown sound id in the Console: the Sounds list in GoldRushAssets is empty, or a file name is wrong (Phase 10, check 6).

Build: “No scenes in build”, or the build starts in a level

Build Profiles → Scene List: MainMenu must be ticked and at index 0, then the levels (Phase 10, check 8).

Android: “Android SDK not found”, or the phone game is portrait

Install Android Build Support with OpenJDK and SDK & NDK in Unity Hub, then restart Unity. In Player Settings, tick only Landscape Left and Landscape Right (Phase 10, step 5).

Your own levels

More problems and fixes are in Practicals, step 15.

My card is not in Level Select

Check the new line in Data.cs (no red errors in the Console) (Practicals, step 6).

Clicking my card: “Scene 'Level5' couldn't be loaded…”

Add the scene to Build Profiles → Scene List (Practicals, step 7).

The intro says “Training Yard” in my level

The scene text in the LevelDef is not the scene file name. Check capital letters and spaces (Practicals, step 6).

I changed Level1 by mistake

You forgot File → Save As. Edit → Undo, or close the scene without saving (Practicals, step 3).

A coin or an orb that I cannot pick up

The coin or orb is not under the level root (the object with Level Scene), so the game does not see it. Drag it onto the level root (for example into Gameplay). Or use the markers from Prefabs/Markers (Practicals, step 1).

I fall through the floor near the new walls

The GroundCollider is too small for your arena. Set its Box Collider Size to 40, 1, 40 (Practicals, step 11).

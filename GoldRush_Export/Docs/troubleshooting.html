Troubleshooting

Something does not work? Find the symptom below. Each answer links to the step that fixes it. Every phase also has its own “Common problems” table at the end.

Try these first
  • Look at the Console (Window → General → Console). The first red error is usually the real cause. Double-click it to open the script at that line.
  • Stop Play mode before you change anything, and wait for Unity to finish compiling (the spinner in the bottom-right corner).
  • Go back to the step and check every value: names, positions, ticked boxes. One wrong letter is enough to break it.
  • Still stuck? Import the checkpoint package of the phase you finished last from GoldRush_Export/Packages/ into a new, empty project and continue from there. Or open it to compare with your project.

Project and packages

Everything is pink

The material uses a shader that URP can't draw. Do not delete the Settings folder of the template. Check Edit → Project Settings → Graphics: Default Render Pipeline must be a URP asset (for example PC_RPAsset). If you made a 3D (Built-In) project by mistake, make a new project with Universal 3D (Phase 0, step 2). One pink material? Set its Shader to Universal Render Pipeline/Lit. A pink model? Select the FBX → Materials tab → Apply.

The template Universal 3D is not in the list

Scroll down in Unity Hub, or click the download icon next to it. Use Unity 6000.6.10f1 or newer (Phase 0, step 2).

I chose Active Input Handling = Both, but nothing happened

Unity must restart. Close Unity yourself and open the project again from Unity Hub (Phase 0, step 6).

“You are trying to read Input using the UnityEngine.Input class…”, or input stopped working

Set Edit → Project Settings → Player → Other Settings → Active Input Handling to Both. The game uses the classic Input class, which does not work with “Input System Package (New)” only (Phase 0, step 6).

Red errors right after importing the starter package

Check that AI Navigation is installed (Phase 0, step 5), then import the package again (step 7).

I cannot find Package Management in the Window menu

In some Unity 6 versions it is Window → Package Manager directly (Phase 0, step 4).

The hero in the test scene is huge or tiny

Scale must be 0.337 on all three axes (Phase 0, step 10).

A kit piece floats above the floor or sinks into it

Set its Position Y to 0. The pivot of every kit piece is at the bottom (Phase 3, step 2).

Scripts and compile errors

Red errors right after importing the helper scripts

Often normal for a moment: the helpers need scripts that you type in the next steps. In phase 1 the errors about Save and GoldRushMenu go away after steps 4–6 (Phase 1, step 3). In phase 7 they go away after you replace the GameManager (Phase 7, step 7).

“The type or namespace name '…' could not be found”

  • The script is missing. Each phase lists the scripts to type or import. Small stubs: VirtualJoystick and TouchLookArea (Phase 4, step 7).
  • A helper is missing: UIKit, Tween, AudioFX, ButtonFX (Phase 1, step 3), EnemyAI, Mats, CharacterFactory, WorldMarkers (Phase 7, step 7), FX (Phase 8, step 3), GameUI and GameAction (Phase 9).
  • The file name and the class name must be the same (PlayerMotor.cs → class PlayerMotor), and the code must be inside namespace GoldRush.

“The namespace 'GoldRush' already contains a definition for …”

A script exists twice, for example two Data.cs or two PowerUp.cs. Search the Project window for the name and delete the extra copy.

“'GameManager' (or 'PlayerMotor') does not contain a definition for …”

You still have an older phase version of the file. Many scripts grow phase by phase. When a step says Replace the whole file, select all the old code and paste the new one. For example GhostActive comes in Phase 7, step 10, SpeedMultiplier in Phase 8, step 10 and AddLantern in Phase 8, step 9.

“'ExitGate' does not contain a definition for …”

An old placeholder of the script is still there. Replace the whole file (Phase 6, step 3).

I can't add a component (Monster Spawn, Enemy AI, …)

Unity can not add components while there are red errors in the Console. Fix them first.

Red errors after replacing all scripts in Phase 10

A file from the Final folder is missing. Copy all folders of Resources/Scripts/Final/ again and click Replace for every file (Phase 10).

My Inspector changes disappeared when I stopped Play

Unity always undoes changes made in Play mode. Write the good value down, stop Play, and type it again. Or right-click the component → Copy Component in Play mode, then Paste Component Values after you stop.

Main menu and UI

Console: “GoldRushAssets missing”

The asset must be called exactly GoldRushAssets and be inside Assets/GoldRush/Resources (Phase 1, step 7).

No music and no click sound

The Sounds list of GoldRushAssets is empty: it needs all 16 .wav files (Phase 1, step 7). Check that the Game view is not muted (Mute Audio).

Buttons do nothing when I click

The scene needs an EventSystem (Phase 1, step 12). Raycast Target must be on for Face (big buttons) or Glass (chips). A big decoration image on top (BackdropTop, LogoGlow, …) with Raycast Target on blocks the clicks: untick it.

Console: “Unknown menu action”

A typo in the Action field of Menu Action. Use exactly play, levels, shop, settings, back or closeSettings (capital S) (Phase 1, step 5, Phase 2, step 2).

The buttons do not grow or glow on hover

Button FX is missing, Flat is not ticked, or a part has another name. It looks for Halo, Face, Edge, EdgeGlow, Sweep, IconDisc, Content and Chevron (Phase 1, step 16).

Round ends of a pill or button look huge or squashed

Image Type must be Sliced, and all layers of one piece need the same Pixels Per Unit Multiplier (for a pill: 128 ÷ height) (Phase 1, step 14). For the phase 2 pieces, use the PPU from the table (Phase 2, step 7).

The gradient or the light sweep sticks out of the button corners

Add a Mask to Face (Phase 1, step 16).

UI looks tiny or huge

Canvas Scaler: Scale With Screen Size, 1920 × 1080, Match 0.5. Game view: Full HD (1920x1080) (Phase 1, step 12).

Text is cut off, or shows in the default font

Font must be Poppins from Resources/Fonts. Horizontal and Vertical Overflow = Overflow (except Best Fit labels).

The logo is missing, or the glows do not pulse

Logo needs the Logo Title component, and it only appears in Play mode (Phase 1, step 15). Glows: Bob Speed and Pulse must not be 0.

The menu hero stands in a T-pose, never waves, or waves once and freezes

Model → Animator → Controller must be Hero, Player Anim on GoldRushMenu must be MenuPlayer/Model, and the parameter must be called exactly Win. The Wave clip needs Loop Time, and the arrow Win → Idle needs Has Exit Time on, Exit Time 3 (Phase 1, step 8).

The menu hero turns his back to the camera

MenuPlayer Rotation Y must be 180 and Model Rotation 0, 0, 0 (Phase 1, step 11).

The menu scene is very dark or very bright in the editor

Normal: the script sets the night mood in Play mode.

NullReferenceException in GoldRushMenu.Start or RefreshTitle

A field on GoldRushMenu is empty, often Gold Text, Stars Text, Stars Bar or Settings Root. Fill every field (Phase 1, step 18, Phase 2, step 12).

The level cards, the tabs or the shop items do not appear

Level Cards, Shop Tabs or Shop Grid is empty, or points to the wrong object. Use Levels/Cards and Shop/ShopPanel/Glass/Tabs / Grid (Phase 2, step 12).

Two screens show at the same time

Each Screen field needs its own screen: Title Screen, Level Screen and Shop Screen (Phase 2, step 12).

The top-right bar shows on the Title screen, or never shows

Top Right must have the three objects under MenuUI, not the ones under Title (Phase 2, step 6).

Settings never opens, opens behind the other screens, or never closes

The gear needs Menu Action settings, CLOSE needs closeSettings. Settings must be the last child of MenuUI (Phase 2, step 10, step 11).

MUSIC / SOUND do nothing, or the label does not change

They need no Menu Action, but they must be in the Music Toggle / Sound Toggle fields. The label must be the first Text inside the button, and the icon disc must be at Glass/IconDisc (Phase 2, step 11).

I click a card behind the Settings dialog, or I can't click anything on the Levels screen

Settings/Dim needs Raycast Target on. Levels/Dim needs Raycast Target off.

PLAY only writes a message in the Console

Normal in phases 1–2: there is no level yet. PLAY opens Level 1 after Phase 3, step 17.

Buying always fails, or the hero does not change colour

You have 0 gold: give yourself some for a test (Phase 2, step 13). The menu hero shows the shop colour and hat from phase 10.

Gold or stars are not saved

Win the level (losing gives only gold for coins). After you change Save.Data in your own code, call Save.Persist(). A “Save corrupted” message in the Console means the save was reset.

I want to start over with no gold and only Level 1 unlocked

Stop Play mode, then Edit → Clear All PlayerPrefs.

Prefabs and the level

I cannot leave Prefab Mode

Click the < arrow at the top left of the Hierarchy, or double-click the scene file.

I changed a kit prefab by mistake (Apply All)

Try Edit → Undo, or import the starter package again and tick only Prefabs (or Materials). Never click Overrides → Apply All on a kit piece (Phase 3, step 2).

Glow materials do not glow

Normal in Edit mode. They shine in Play mode, when EnvironmentSetup adds bloom.

The name in the Hierarchy is not blue

It is not a prefab instance. Delete it and drag the prefab from the Project window again.

Blocks float or sink into the floor

Y must be 0 (only block #10 has Y 2). Floor_40m must be at 0, 0, 0 (Phase 3, step 6, step 11).

A wall piece is far away from where it should be

It is not a child of its wall group, so its position is in world space. Drag it onto the right group and type the local position again (Phase 3, step 7). East/west walls run the wrong way? Rotate the group (0, 90, 0), not the children (Phase 3, step 9).

The sky is grey, there is no fog, or everything is dark

Window → Rendering → Lighting → Environment: Skybox Material = GR_SunsetSky, Fog ticked, Linear, Start 35, End 120. In the Scene view, turn on Fog in the effects menu. Sun Intensity 1.5 and the gradient ambient colours (Phase 3, step 13 and step 14).

I cannot see the markers

Give them an icon, and check that Gizmos is on in the Scene view toolbar (Phase 3, step 12).

Game view: “No cameras rendering”

You deleted the Main Camera. Add one with GameObject → Camera, tag it MainCamera (Phase 3, step 16).

PLAY does nothing: “Scene 'Level1' couldn't be loaded because it has not been added to the build settings”

Add the scene to File → Build Profiles → Scene List. The name must be exactly Level1, no space (Phase 3, step 17).

A level card for Level 2, 3 or 4 gives the same error

Normal: only Level 1 exists until phase 10 (Phase 10).

The build (or Play from the menu) starts in Level1, not in the menu

In the Scene List, MainMenu must be number 0. Drag it to the top (Phase 3, step 17).

Player and animation

The hero model is grey, white or pink

Select Hero.fbx → Materials tab → Import via MaterialDescription, Use Embedded Materials → Apply (Phase 4, step 2).

The hero stands in a “T” pose

The Animator on Model has no Controller. Drag Hero into it (Phase 4, step 12). The Animator is on the child Player/Model, not on Player.

The hero slides, but always plays Idle

The parameter is not called exactly Speed (Phase 4, step 3), or the blend tree Parameter is not Speed (step 4).

Walk or run plays once and then freezes

Loop Time is off for that clip. Tick it in the Animation tab of the FBX and click Apply (Phase 4, step 2). Same for the monsters (Phase 7, step 4).

The hero runs when he should walk

Untick Automate Thresholds and set 0 / 0.5 / 1 (Phase 4, step 4).

The hero moves away from his capsule, floats, sinks, or is tiny or giant

Untick Apply Root Motion on the Animator. Model Position = 0, 0, 0, Scale about 0.36: change the Scale of Model, not of Player (Phase 4, step 12). CharacterController Center = 0, 0.695, 0, Height = 1.35 (step 11).

The hero's feet slide, or he runs in slow motion

Check the Hero values in GoldRushAssets: Height 1.35, Walk Speed 0.59, Run Speed 0.84 (Phase 5, step 9).

The hero falls through the floor

The floor has no collider, or the Player starts below the floor.

Nothing happens when I press keys

Click inside the Game view first. Check that PlayerMotor is on Player and is ticked (Phase 4, step 13).

A trigger (Attack, Hit, Win, Die) does nothing, or the hero stays in that animation

The Any State arrow needs a condition with the right trigger. The arrow back to Locomotion must exist, with Has Exit Time on (Phase 4, step 6).

I can't find the Slime's Hit clip

The model spells it HitRecieve (with “ie”). Ghost and Mushroom King use HitReact (Phase 7, step 5).

Camera and mouse

The camera does not move

Target on ThirdPersonCamera is empty. Drag Player into it (Phase 4, step 14).

The camera is very close to the hero, or jumps in and out

The Player and its Model must be on the Ignore Raycast layer (Phase 4, step 13). An invisible object with a collider can also block the camera: remove that collider.

W always runs the same way, not where the camera looks

Cam on PlayerMotor is empty (Phase 4, step 15).

The mouse does not turn the camera, or the cursor never hides

Click inside the Game view so the cursor locks. On a touch-screen computer mouse look stays off: use right-drag or Q/E (Phase 4, step 9).

The mouse cursor disappeared

The game hides and locks it so the mouse can turn the camera. Press Esc to get it back. Click in the Game view to lock it again.

The camera looks through walls

The wall has no collider. Open the wall prefab in Prefab Mode and check that its solid parts still have a Box Collider (Phase 3, step 2).

The camera shakes when the hero runs

There must be only one ThirdPersonCamera, and the camera must not be a child of Player (Phase 4, step 14).

Coins, gate, win and lose

Console: “No LevelScene in this scene”

Add the Level Scene component to the level root Level 1 - Training Yard (Phase 5, step 11).

Console: “CoinSpot 3 has no Coin inside”

Drag the Coin prefab onto that marker and set its Position to 0, 1, 0 (Phase 5, step 13).

Console: “collect 0 coins”, or “This level has no coins”

The CoinSpots need the Coin Spot component, and they must be inside the level root (Phase 5, step 12).

Where is the coin counter?

There is no HUD until phase 9. Until then the Console counts for you: Coin 1 / 6 (Phase 5, step 16).

I walk through a coin but nothing happens

Coins have no colliders: the GameManager checks the distance every frame (Phase 5, step 2). The child Coin must be at local position 0, 1, 0 and the marker on the floor (Y = 0). Check that the GameManager is in the scene (step 15).

The coins do not spin

The Coin prefab has no Coin component, or its Visual field is empty (Phase 5, step 10).

The hero does not move after GO

Replace PlayerMotor.cs with the phase 5 version (Phase 5, step 6). There must be exactly one GameManager.

NullReferenceException in GameManager.Build

The scene has no Player (with PlayerMotor) or no camera (with ThirdPersonCamera). The GameManager looks for both (Phase 5, step 14).

No coin sound. Console: “[AudioFX] Unknown sound id: coin”

The Sounds list in GoldRushAssets is empty, or the file is not called coin.wav. The file name is the sound id (Phase 1, step 7, Phase 5, step 9).

The level looks very different in Play mode

Normal: EnvironmentSetup sets the game's own sky, fog and glow. Too bright? Delete an extra Global Volume from your scene.

All coins collected, but the gate does not open

The gate needs the Exit Gate component and its Door field filled, and it must be inside the level root (Phase 6, step 5, step 6).

The gate opens, but the strips stay red

Fill the Strips list and the Green Strip material (M_GlowGreen) (Phase 6, step 5).

The green pad is visible before the gate opens

Untick the Glow object in the prefab (Phase 6, step 5).

I stand at the gate and nothing happens

The gate opens only after all coins. The gate rotation must be 0, 0, 0: the win point is on its -Z side (Phase 6, step 6).

The gate door does not move, and the strips turn green at once

The gate is marked Static. Untick Static on ExitGate and its children. Only the Static group is static (Phase 3, step 15).

The hero walks out through the open gate

The invisible GateBlocker is missing (Phase 3, step 8, Phase 6, step 7).

The hero does not wave at the end

The Hero controller needs the Win trigger and the Win state (Phase 4, step 3, step 5).

After the win: “Scene 'MainMenu' couldn't be loaded”

Add MainMenu to File → Build Profiles → Scene List, at number 0 (Phase 3, step 17).

Where is the win dialog? The game goes straight back to the menu

Normal until phase 9. In phase 6 the stars are written in the Console and the game goes back to the menu. After a loss the level loads again (Phase 6, step 2).

Pressing L does nothing

Press it after GO!, while you play. Check that you replaced the GameManager (Phase 6, step 8).

Monsters

Error: “The type or namespace name 'EnemyAI' could not be found”, or 'Mats' / 'CharacterFactory' / 'WorldMarkers'

Import all helpers from Phase 7, step 7.

Monsters stand still. Console: “SetDestination” can only be called on an active agent…

Bake the NavMesh, and check that the monster stands on the blue area, not inside a block or outside the walls (Phase 7, step 3, step 13).

The monster is invisible in Play mode

Fill Model and Controller for that monster in GoldRushAssets (Phase 7, step 6).

The badge, the glow or the monster is pink

Fill Lit and Lit Emissive in GoldRushAssets (Phase 7, step 6). A pink monster model: click the FBX → Materials tab → Apply.

Monsters walk through walls

The wall has no collider, it is not inside Static, or you moved it after baking. Fix it and click Bake again (Phase 7, step 3).

Monsters never see me

Something with a collider is in the way. The hero himself is fine: the GameManager puts him on the Ignore Raycast layer. In GHOST mode they can't see you on purpose.

A monster slides without moving its legs

Its controller has no clips, or the Walk clip has no Loop Time (Phase 7, step 4, step 5).

There are 2 monsters at one spot

You kept an old empty marker that also has a Monster Spawn component. Delete it (Phase 7, step 13).

Hearts don't go down

Replace GameManager with the phase 7 version (Phase 7, step 10). The hearts on the screen come with the HUD in phase 9 (Phase 7, step 14). With no hearts left, you lose the level.

Monsters got faster after I took the last coin

That is on purpose: AllCollected() makes every monster 10% faster for the race to the exit.

Power-ups and effects

Error: “The name 'FX' does not exist”

Import FX.cs (Phase 8, step 3).

Console: “PowerUp Magnet has no PowerUp inside”

Drag the PowerUp prefab onto the marker and set its Position to 0, 0, 0 (Phase 8, step 7).

No orb appears, or it does not float or spin

The marker must be inside the level root and have a Power Up Spot (Phase 8, step 7). The prefab needs the Power Up component with Visual and Ring filled (Phase 8, step 6).

I walk into the orb and nothing happens

The orb must be at local position 0, 0, 0 in a marker on the floor. Walk right through it. Check that the GameManager is the phase 8 version (Phase 8, step 10).

SPEED gives the wrong effect (for example MAGNET)

The Type on the PowerUp prefab is wrong (Phase 8, step 6). Use the same type on the marker.

SPEED does not make me faster

Replace PlayerMotor with the phase 8 version (Phase 8, step 9).

Monsters still see me in GHOST mode

Check that EnemyAI.cs is the helper from phase 7: Vision() starts with if (gm.GhostActive) return false; (Phase 7, step 7).

Particles are pink squares

Open GoldRushAssets and set Particle = GR_Particle (Phase 7, step 6).

No dust behind the player

The player must move faster than 1 m/s. Check that you replaced the PlayerMotor (Phase 8, step 9).

HUD and dialogs

The game UI is built by hand as GameObjects in the level scene, in the same glass style as the menu. GameUI connects the pieces, and each button has a GameAction (Phase 9).

Buttons in the HUD or the dialogs do nothing

The level scene needs an EventSystem. Each button needs Game Action (not Menu Action) with one of these words: pause, resume, retry, menu, next. “Unknown game action” in the Console means a spelling mistake. Check Raycast Target, like in the menu (Main menu and UI).

NullReferenceException in GameUI

A field on GameUI is empty. Drag every HUD and dialog object into its field (Phase 9).

Errors about Markers, Joystick or PowerUp in GameUI

A script is missing or old: WorldMarkers (phase 7), PowerUp (phase 8), VirtualJoystick (phase 4). Import or replace the file the guide names (Phase 9).

Round ends look wrong, or the HUD looks tiny or huge

Same fixes as the menu: Image Type Sliced with the right PPU, and Canvas Scaler 1920 × 1080, Match 0.5 (Phase 1, step 12, step 14). Reuse your glass prefabs from Prefabs/UI.

A full-screen panel blocks the clicks or the joystick

Images catch clicks and touches when Raycast Target is on. Untick it on images that are only decoration.

My UI animation freezes in the pause menu

Pause sets Time.timeScale = 0. Use Time.unscaledDeltaTime or WaitForSecondsRealtime. Tween already uses unscaled time.

NEXT or MENU: “Scene … couldn't be loaded”

Every scene must be in the Scene List (Phase 3, step 17). NEXT needs Levels 2–4, which come in Phase 10.

Day/night, touch, sound and build

Pressing N does nothing

The level has no DayNight yet, or EnvironmentSetup.cs is not the final version (Phase 10).

Floor and walls do not change colour at night

The palette must be at Assets/GoldRush/Resources/DayNightPalette.asset (exact name). The level root needs a Day Night Tint (Phase 10).

After Play, my material stays dark blue

Something changed the material asset itself. Use Day Night Tint, which works on copies, and set the colour back by hand.

Lamps shine during the day, or a new light is on by day

Add a Night Light component to the light (Phase 10).

Touch does nothing in the Simulator

Click on the Simulator screen, not outside it. You need an EventSystem, and Active Input Handling = Both (Phase 0, step 6, Phase 10).

No sound or no music

  • Check Mute Audio at the top of the Game view.
  • Check MUSIC and SOUND in the game's Settings. They are saved, so they stay off next time (Phase 2, step 11).
  • [AudioFX] Unknown sound id in the Console: the Sounds list in GoldRushAssets is empty, or the file name is wrong. The file name is the sound id (Phase 1, step 7).

Build: “No scenes in build”, or the build starts in a level

Build Profiles → Scene List: MainMenu must be ticked and at index 0, then the levels (Phase 3, step 17, Phase 10).

Android: “Android SDK not found”, or Switch Platform is grey

Install Android Build Support with OpenJDK and SDK & NDK in Unity Hub, then restart Unity (Phase 10).

The phone game is portrait

Player Settings → Resolution and Presentation: tick only Landscape Left and Landscape Right.

Troubleshooting

Something does not work? Find the symptom below. Each answer links to the step that fixes it. Every phase also has its own “Common problems” table at the end.

Try these first
  • Look at the Console (Window → General → Console). The first red error is usually the real cause. Double-click it to open the script at that line.
  • Stop Play mode before you change anything, and wait for Unity to finish compiling (the spinner in the bottom-right corner).
  • Go back to the step and check every value: names, positions, ticked boxes. One wrong letter is enough to break it.
  • Still stuck? Import the checkpoint package of the previous phase from GoldRush_Export/Packages/ into a new, empty project and continue from there. Or open it to compare with your project.

Project and packages

Everything is pink

The material uses a shader that URP can't draw. Check Edit → Project Settings → Graphics: Default Render Pipeline must be a URP asset (for example PC_RPAsset). If you made a 3D (Built-In) project by mistake, make a new project with Universal 3D (Phase 0, step 2). One pink material? Set its Shader to Universal Render Pipeline/Lit. A pink model? Select the FBX → Materials tab → Apply.

The template Universal 3D is not in the list

Scroll down in Unity Hub, or click the download icon next to it. Use Unity 6000.6.10f1 or newer (Phase 0, step 2).

I chose Active Input Handling = Both, but nothing happened

Unity must restart. Close Unity yourself and open the project again from Unity Hub (Phase 0, step 6).

“You are trying to read Input using the UnityEngine.Input class…”, or input stopped working

Set Edit → Project Settings → Player → Other Settings → Active Input Handling to Both. The game uses the classic Input class, which does not work with “Input System Package (New)” only (Phase 0, step 6).

The hero model is grey or white

Select Hero.fbx → Materials tab → Location: Use Embedded Materials → Apply (Phase 3, step 2).

Red errors right after importing the starter package

Check that AI Navigation is installed (Phase 0, step 5), then import the package again (step 7).

I cannot find Package Management in the Window menu

In some Unity 6 versions it is Window → Package Manager directly (Phase 0, step 4).

Scripts and compile errors

“The type or namespace name '…' could not be found”

  • The script is missing. Each phase lists the scripts to type or import. Small stubs come first: VirtualJoystick (Phase 3, step 8), TouchLookArea (Phase 4, step 3).
  • A helper is missing: GameUI / UIKit (Phase 5, step 6), EnemyAI (Phase 7, step 8), FX (Phase 8, step 3).
  • The file name and the class name must be the same (PlayerMotor.cs → class PlayerMotor), and the code must be inside namespace GoldRush.

“The namespace 'GoldRush' already contains a definition for …”

A script exists twice, for example two Data.cs or two PowerUp.cs. Search the Project window for the name and delete the extra copy.

“'GameManager' does not contain a definition for …”

You still have an older version of the file. Many scripts grow phase by phase. When a step says Replace the whole file, select all the old code and paste the new one. For example GhostActive comes in Phase 7, step 10.

Errors about BackToMenu, Markers or PowerUp in GameUI

You imported a helper from a later phase. Some helpers have a short version for an early phase, in a folder like Helpers/Phase06/. Use the folder that the step names.

“'ExitGate' does not contain a definition for …”

The placeholder script from Phase 5 is still there. Replace the whole file (Phase 6, step 3).

Red errors after replacing all scripts in Phase 10

A file from the Final folder is missing. Copy all six folders again and click Replace for every file (Phase 10, step 13).

My Inspector changes disappeared when I stopped Play

Unity always undoes changes made in Play mode. Write the good value down, stop Play, and type it again. Or right-click the component → Copy Component in Play mode, then Paste Component Values after you stop.

Prefabs and the level

I cannot leave Prefab Mode

Click the < arrow at the top left of the Hierarchy, or double-click the scene file (Phase 1, step 6).

I changed one copy and want to undo it

Select the instance root → Overrides → Revert All (Phase 1, step 8). Do not click Apply All on the kit pieces.

I changed a kit prefab or a material by mistake

Try Edit → Undo. A changed material? M_BlockTop is EDF0F7, M_Block is CCD1DB (Phase 1, step 7). Or import the starter package again and tick only Prefabs or Materials.

Glow materials do not glow

Normal at first. They shine when the game adds bloom with the post-processing (Phase 10, step 7).

The name in the Hierarchy is not blue

It is not a prefab instance. Delete it and drag the prefab from the Project window again.

A block floats above the floor or sinks into it

Set its Position Y to 0. The pivot of every kit piece is at the bottom (Phase 1, step 5). Check the floor position too (Phase 2, step 6).

A wall piece is far away from where it should be

It is not a child of its wall group, so its position is in world space. Drag it onto the right group and type the local position again (Phase 2, step 7). East/west walls run the wrong way? Rotate the group (0, 90, 0), not the children (Phase 2, step 9).

The floor grid is one giant tile, or missing

Use the floor from the kit. M_Floor needs the grid texture in Base Map and Tiling 20, 20 (Phase 2, step 6).

The sky is grey, there is no fog, or everything is dark

Window → Rendering → Lighting → Environment: Skybox Material = GR_SunsetSky, Fog ticked, Linear, Start 35, End 120. Check the Sun Intensity (1.5) (Phase 2, step 13 and step 14).

Grid snapping does nothing

It only works with the Move tool in Global handle mode. Or type the numbers in the Inspector (Phase 2, step 5).

I cannot see the markers

Give them an icon, and check that Gizmos is on in the Scene view toolbar (Phase 2, step 12).

Game view: “No cameras rendering”

You deleted the Main Camera. Add one with GameObject → Camera, tag it MainCamera (Phase 2, step 16).

Player and animation

The hero stands in a “T” pose

The Animator on Model has no Controller. Drag Hero into it. Also check the Avatar (Phase 3, step 12). The Animator is on the child Player/Model, not on Player.

The hero slides, but always plays Idle

The parameter is not called exactly Speed (Phase 3, step 4), or the blend tree Parameter is not Speed (step 5).

Walk or run plays once and then freezes

Loop Time is off for that clip. Tick it in the Animation tab of the FBX and click Apply (Phase 3, step 3). Same for the monsters (Phase 7, step 4).

Walk and run look mixed up

Untick Automate Thresholds and set 0 / 0.5 / 1 (Phase 3, step 5).

The hero moves away from his capsule, floats or sinks

Untick Apply Root Motion on the Animator. Model Position = 0, 0, 0. CharacterController Center = 0, 0.695, 0, Height = 1.35 (Phase 3, step 12, step 11).

The hero falls through the floor

The floor has no collider, or the Player starts below the floor.

Nothing happens when I press keys

Click inside the Game view first. Check that PlayerMotor is on Player and is ticked (Phase 3, step 13).

A trigger (Attack, Hit, Win, Die) does nothing, or the hero stays in that animation

The Any State arrow needs a condition with the right trigger. The arrow back to Locomotion must exist, with Has Exit Time on (Phase 3, step 7).

I can't find the Slime's Hit clip

The model spells it HitRecieve (with “ie”). Ghost and Mushroom King use HitReact (Phase 7, step 5).

Camera and mouse

The camera does not move

Target on ThirdPersonCamera is empty. Drag Player into it (Phase 4, step 7).

The camera is very close to the hero, or jumps in and out

The Player (and its children) must be on the Ignore Raycast layer (Phase 4, step 9). An invisible object with a collider can also block the camera: remove that collider.

W always runs the same way, not where the camera looks

Cam on PlayerMotor is empty (Phase 4, step 8), or you still have the Phase 3 PlayerMotor (step 5).

The mouse does not turn the camera, or the cursor never hides

Click inside the Game view so the cursor locks. You can also hold the right mouse button and drag (Phase 4, step 10).

The mouse cursor disappeared

The game hides and locks it so the mouse can turn the camera. Press Esc to get it back. Click in the Game view to lock it again.

The camera looks through walls

The wall has no collider. Open the wall prefab in Prefab Mode and check that its solid parts still have a Box Collider (Phase 1, step 6).

The camera shakes when the hero runs

There must be only one ThirdPersonCamera, and the camera must not be a child of Player (Phase 4, step 6).

Coins, gate, win and lose

Console: “No LevelScene in this scene”

Add the Level Scene component to the level root Level 1 - Training Yard (Phase 5, step 14).

The counter shows 0 / 0 and the Console says “This level has no coins”

Each Coin must be a child of an object with the Coin Spot component, and the CoinSpots must be inside the level root (Phase 5, step 14).

I walk through a coin but nothing happens

Coins have no colliders: the GameManager checks the distance every frame (Phase 5, step 2). The child Coin must be at local position 0, 1, 0 and the marker on the floor (Y = 0). Check that the GameManager is in the scene (step 15).

The coins do not spin

The Visual field of the Coin prefab is empty. Open the prefab and drag Visual into it (Phase 5, step 13).

NullReferenceException in GameManager

The scene has no Player (with PlayerMotor) or no camera (with ThirdPersonCamera). The GameManager looks for both.

Console: “GoldRushAssets missing”, or pink sky and objects after Phase 5

The asset must be called GoldRushAssets and be inside Assets/GoldRush/Resources. Fill every material field on it (Phase 5, step 12).

All coins collected, but the gate does not open

The gate needs the Exit Gate component and its Door field filled. The strips stay red? Fill the Strips list and the Green Strip material (Phase 6, step 5).

I stand at the gate and nothing happens

The gate opens only after all coins. The gate rotation must be 0, 0, 0: the win point is on its -Z side.

The gate door does not move, and the strips turn green at once

The gate is marked Static. Untick Static on ExitGate and its children. Only the Static group is static (Phase 2, step 15).

The hero walks out through the open gate

The invisible GateBlocker from Phase 2 is missing (Phase 2, step 8, and the tip in Phase 6, step 6).

The hero can move during the countdown, or does not wave at the end

Replace PlayerMotor.cs with the Phase 6 version (Phase 6, step 7). The Animator needs the Win and Die triggers (Phase 3, step 4).

“Scene 'Level1' couldn't be loaded because it has not been added to the build settings”

Add the scene to File → Build Profiles → Scene List (Phase 5, step 15, later Phase 9, step 17). The name must match exactly.

NEXT or MENU: “Scene … couldn't be loaded” in Phase 6

Normal for now. The menu and the other levels come in Phase 9.

The timer stays at 0:00.0

The intro never ended. Look for a red error in the Console during the countdown.

Monsters

Monsters stand still. Console: “SetDestination” can only be called on an active agent…

Bake the NavMesh, and check that the monster stands on the blue area, not inside a block or outside the walls (Phase 7, step 3).

Monsters walk through walls

The wall has no collider, or you moved it after baking. Add a Box Collider and click Bake again. Walls must be under Static.

Monsters never see me

Put the Player and its children on the Ignore Raycast layer (Phase 7, step 14). In GHOST mode they can't see you on purpose.

A monster slides without moving its legs

Its Model has no Controller, or the Walk clip has no Loop Time (Phase 7, step 5, step 11).

There are 2 monsters at one spot

An old empty object with only MonsterSpawn on it makes a monster by code. Delete it (Phase 7, step 13).

Hearts don't go down, or there are no hearts

Replace GameManager with the Phase 7 version (Phase 7, step 10).

Monsters got faster after I took the last coin

That is on purpose: AllCollected() makes every monster 10% faster for the race to the exit.

Power-ups and effects

No orb appears

The marker must be inside the level root and have a PowerUpSpot (Phase 8, step 9). The GameManager must be the Phase 8 version (step 7).

SPEED does not make me faster

Replace PlayerMotor with the Phase 8 version (Phase 8, step 6).

Particles are pink squares

Open GoldRushAssets and set Particle = GR_Particle (URP Particles/Unlit) (Phase 8, step 3).

No dust behind the player

The player must move faster than 1 m/s. Check that you have the Phase 8 PlayerMotor.

Menu, levels and saving

Buttons do nothing when I click

The scene needs an EventSystem (Phase 9, step 8). Each button needs Menu Action with a correct action name. “Unknown menu action” in the Console means a spelling mistake (Phase 9, step 5).

Level cards, shop items, or a NullReferenceException in GoldRushMenu.Start

A field on GoldRushMenu is empty, often Level Cards, Shop Grid, Title Gold Text or Stars Bar. Fill every field (Phase 9, step 14).

Two screens show at the same time, two heroes, or a black screen

Each Screen field needs a different screen. Delete the Main Camera from MainMenu: the menu makes its own camera (Phase 9, step 7).

Round button ends look huge or squashed. UI looks tiny or huge

Image Type Sliced with the right Pixels Per Unit Multiplier. Canvas Scaler: Scale With Screen Size, 1920 × 1080, Match 0.5 (Phase 9, step 8).

A new full-screen panel blocks the clicks or the joystick

Images catch clicks and touches when Raycast Target is on. Untick it on images that are only decoration.

Level 2 has the wrong number of coins

Coins come from the CoinSpot objects in the scene. Count them under the level root (Phase 9, step 15).

Gold or stars are not saved

Win the level (losing gives only gold for coins). After you change Save.Data in your own code, call Save.Persist(). A “Save corrupted” message in the Console means the save was reset.

I want to start over with no gold and only Level 1 unlocked

Stop Play mode, then Edit → Clear All PlayerPrefs.

My UI animation freezes in the pause menu

Pause sets Time.timeScale = 0. Use Time.unscaledDeltaTime or WaitForSecondsRealtime. Tween already uses unscaled time.

Day/night, touch, sound and build

Pressing N does nothing

The level has no DayNight. Check that EnvironmentSetup.cs is the final version (Phase 10, step 7).

Floor and walls do not change colour at night

The palette must be at Assets/GoldRush/Resources/DayNightPalette.asset (exact name). The level root needs a Day Night Tint (Phase 10, step 6). “Create → Gold Rush → Day Night Palette” missing? Add the [CreateAssetMenu] line (step 5).

After Play, my material stays dark blue

Something changed the material asset itself. Use Day Night Tint, which works on copies, and set the colour back by hand.

Lamps shine during the day, or a new light is on by day

Add a Night Light component to the light (Phase 10, step 4).

Touch does nothing in the Simulator

Click on the Simulator screen, not outside it. You need an EventSystem, and Active Input Handling = Both (Phase 10, step 11).

No sound or no music

  • Check Mute Audio at the top of the Game view.
  • Check MUSIC and SOUND in the game's Settings. They are saved, so they stay off next time.
  • [AudioFX] Unknown sound id in the Console: the Sounds list in GoldRushAssets is empty, or the file name is wrong. The file name is the sound id (Phase 5, step 12).

Build: “No scenes in build”, or the build starts in a level

Build Profiles → Scene List: MainMenu must be ticked and at index 0 (Phase 10, step 15).

Android: “Android SDK not found”, or Switch Platform is grey

Install Android Build Support with OpenJDK and SDK & NDK in Unity Hub, then restart Unity (Phase 10, step 16).

The phone game is portrait

Player Settings → Resolution and Presentation: tick only Landscape Left and Landscape Right.

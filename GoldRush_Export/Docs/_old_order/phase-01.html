GOLD RUSH · Phase 1

The prefab kit

The starter package gives you a ready-made prefab kit: floor, blocks, walls, a pillar, a lamp post and more, plus the models of the coin, the gate and the power-ups. You take a short tour: what a prefab is, how to look inside one, and how a prefab and its copies in the scene work together. In phase 2 you build the whole level from this kit.

1What you need

  • The project from Phase 0 (or import GoldRush_Phase00_Project.unitypackage into a new Universal 3D project).
  • Open the scene Assets/GoldRush/Scenes/Sandbox.unity.
  • No new packages. No scripts in this phase.

2What is a prefab?

A prefab is a saved GameObject (with its children and components) stored as a file in the Project window. You can place it in a scene many times. Each copy in a scene is an instance. When you change the prefab file, every instance changes too.

The kit pieces are made of simple cubes. A block, for example, has:

  • a root object with the prefab's name,
  • a Body cube with the material M_Block (light grey),
  • a thin Top cube with M_BlockTop (a bit lighter), so the block looks bevelled.
Pivot at the bottom. The root's position is the centre of the block's bottom face. So a piece at Y = 0 stands exactly on the floor. You never have to lift blocks by half their height.

5Place some kit pieces

  1. Drag Block_1x1x1 from the Project window into the Scene view, next to the hero. Do it three times.
  2. Drag in one Wall_8m, one Pillar and one LampPost.
  3. For each one, check that Position Y is 0 in the Inspector. Move them so they do not overlap.

The names in the Hierarchy are blue. Blue means: this is a prefab instance.

6Look inside with Prefab Mode

Prefab Mode is a view where you see and edit one prefab file on its own.

  1. In the Project window, double-click LampPost. The Scene view shows only the lamp, on a blue background.
  2. In the Hierarchy, click each child one by one: the dark base and pole, the glowing cap, the light-grey hat on top, and LampLight. Each child is a simple cube with one material.
  3. Select LampLight. In the Inspector it is a Point Light: Intensity 2.4, Range 9, no shadows (cheap for phones).
  4. Select the glowing cap. It has no Box Collider: only the base and the pole are solid.
  5. Click the < arrow at the top of the Hierarchy to leave Prefab Mode. Do not change anything.

7Try it: change a colour

This step is optional. It shows that many objects share one material.

  1. In Assets/GoldRush/Materials, click M_BlockTop.
  2. In the Inspector, click the colour box next to Base Map. Pick a bright yellow.
  3. Look at the Scene: the tops of all blocks, the wall and the pillar are yellow now.
  4. Change it back: type EDF0F7 in the Hexadecimal field and press Enter.
A material is shared. Changing it changes every object that uses it, in every scene. Always set it back.

8Instance, override, revert

  1. Select one Block_1x1x1 in the scene. Open it in the Hierarchy and select its Top.
  2. Drag M_Red from the Project window onto the Top. Only this one block changes.
  3. Look at the Inspector: the changed value is bold with a blue line at the left. This is an override: a change on one instance only.
  4. Select the block's root. At the top of the Inspector, click Overrides. The list shows your change.
  5. Click Revert All. The block is normal again.
  6. Save the scene.
You change…What changes
The prefab file (in Prefab Mode)Every instance in every scene.
One instance in the sceneOnly that instance (an override). Overrides → Apply All would copy it to the prefab file. Do not do this with the kit.
Position and rotation of an instanceOnly that instance. This is normal: you place every piece somewhere else.
A materialEvery object that uses the material.

9▶ Press Play

  1. Click ▶ Play. Move the Main Camera if you cannot see the pieces (for example Position 0, 3, -8, Rotation 15, 0, 0).
  2. Click ▶ again to stop.

You should see:

  • A test scene with the hero, three grey blocks with light tops, a wall, a pillar with a cyan band and a lamp post.
  • All kit pieces stand on the floor (none float or sink).
  • No red errors in the Console.

10Common problems

ProblemFix
A piece floats or sinks into the floor.Set its Position Y to 0. The pivot is at the bottom.
Pieces are pink.The URP settings are missing (see Phase 0, Common problems).
All blocks changed colour, and I want the old colour back.You changed a material. M_BlockTop is EDF0F7, M_Block is CCD1DB. Or import the starter package again and tick only Materials.
I changed a prefab by mistake (Apply All).Edit → Undo, or import the starter package again and tick only Prefabs.
The name in the Hierarchy is not blue.It is not a prefab instance (maybe you unpacked it). Delete it and drag the prefab from the Project window again.
Glow materials do not glow.Normal for now. Bloom comes with the game's post-processing in a later phase.
I cannot leave Prefab Mode.Click the < arrow at the top left of the Hierarchy, or double-click the scene file.

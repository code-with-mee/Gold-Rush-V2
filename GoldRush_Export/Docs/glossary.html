GOLD RUSH · Help

Glossary

Words used in this course, A to Z. After each word you find a link to the step where it is used or explained best.

Active Input Handling
A Player Setting that chooses which input system Unity uses. Gold Rush needs Both: the code uses the classic Input class, and the UI uses the Input System package. Unity restarts when you change it. → Phase 0, step 6
Anchor
The point of the parent a UI element is attached to, from (0, 0) bottom-left to (1, 1) top-right. “Top left” keeps the gold chip in the corner on every screen size. Stretch / stretch makes a screen fill the whole Canvas. → Phase 1, step 12
Animator Controller
An asset that decides which animation plays: states, transitions (arrows) and parameters. You make a small one for the waving hero in the menu, build the full hero controller by hand, and make one for each monster. → Phase 1, step 8, Phase 4, step 3
Any State
A special box in the Animator. An arrow from Any State can start from every state, for example “play Hit when the Hit trigger fires”. → Phase 4, step 6
Bake (NavMesh)
Let Unity calculate the walk map once and save it. Bake again after you move a wall. → Phase 7, step 3
Blend tree
An Animator state that mixes several clips using a number. The Locomotion blend tree mixes Idle (0), Walk (0.5) and Run (1) with the Speed parameter. → Phase 4, step 4
Build Profiles (Scene List)
The window where you choose the platform and the scenes that go into the game. A scene that is not in the list cannot be loaded. MainMenu must be first (index 0), Level1 comes next. → Phase 3, step 17
Canvas
The root object of a Unity UI. Every image, text and button must be inside a Canvas. The menu Canvas is called MenuUI. The game UI of phase 9 is built the same way. → Phase 1, step 12
Canvas Group
A component that fades or blocks a whole UI group at once (alpha, interactable). The menu uses it to fade each screen in. → Phase 1, step 12
CC0
A “no rights reserved” licence. The Quaternius characters are CC0, so you can use them in any project, even commercially. → Phase 0, step 7
CharacterController
A Unity component that moves a capsule with Move() and stops at walls, without physics forces. Used for the hero (Height 1.35, Center Y 0.695). → Phase 4, step 11
Checkpoint package
A .unitypackage file with the project as it is at the end of a phase, for example GoldRush_Phase03_Level. Import it into a new, empty project if you get lost. → Overview: checkpoint packages
Collider
An invisible shape that other objects bump into. Walls need one so the hero stops, the camera stops, and the NavMesh leaves a hole. Glowing caps and decoration have none. The invisible GateBlocker is only a collider. → Phase 3, step 2
Coroutine
A method that can pause with yield return and continue later, for example to wait a second. The camera intro and the win/lose sequences are coroutines. → Phase 5, step 8
Dead zone
A small area around the centre of a joystick that counts as “not pushed”. In Gold Rush, stick values under 0.12 count as zero. → Phase 10
Device Simulator
A Game view mode that shows a phone screen and turns mouse clicks into touches. Use it to test the touch controls. → Phase 10
Emission
A material setting that makes a surface glow with its own colour, even in the dark. Used for the lamp caps, the gold and the gate strips. It really shines once EnvironmentSetup adds bloom. → Phase 3, step 2
Event (C#)
A list of methods to call when something happens. DayNight.Changed tells every sun/moon button that the time of day changed. Subscribe with +=, unsubscribe with -=. → Phase 1, step 3, Phase 10
EventSystem
The object that sends clicks and touches to the UI. Unity adds it with the first Canvas. Without it, no button works. → Phase 1, step 12
Field of view (view cone)
How wide a monster can see. The Slime sees 130° in front, the Mushroom King 200°, the Ghost all around. → Phase 7, step 2
Fog
Makes far-away things fade into a colour. Gold Rush uses Linear fog from 35 to 120 m. → Phase 3, step 14
GameAction
The small script on every button of the game UI (pause, resume, retry, menu, next). On click it plays the click sound and calls GameManager.Run(action). It works like MenuAction in the menu. → Phase 9
GoldRushAssets
The GameAssets data file in Assets/GoldRush/Resources. It tells the scripts where the hero and monster models, the base materials, the sky and the 16 sounds are. You make it in phase 1 and fill more fields in phases 5 and 7. → Phase 1, step 7
Has Exit Time
A setting on an Animator arrow: wait until the clip is (almost) finished before you switch. On for the arrows back from Hit and Win, off for arrows that must react at once. → Phase 4, step 6
Helper script
A big script (more than about 250 lines) that you import from Resources/Scripts/Helpers/ instead of typing, for example UIKit, EnemyAI or FX. The guide explains the few functions you call. → Phase 1, step 3
HUD
“Heads-up display”: the game UI that stays on screen while you play: coins, hearts, timer, the day/night and pause buttons. → Phase 9
Ignore Raycast layer
A built-in layer that rays do not hit. The Player is on it, so the camera's wall check and the monsters' view check do not hit the hero himself. → Phase 4, step 11
JSON
A text format for data. The save file is a SaveData object turned into JSON with JsonUtility. → Phase 1, step 4
LateUpdate
Called every frame after all Update() methods. The camera uses it, so it follows a hero that has already moved. → Phase 4, step 9
Lerp
Linear interpolation: Lerp(a, b, t) goes t of the way from a to b. Works for numbers, vectors and colours. The hero's speed eases with it, and the day/night blend is one big Lerp. → Phase 4, step 8
Level root (LevelScene)
The top object of a level, Level 1 - Training Yard. It has the Level Scene component. The GameManager only finds coins, power-ups and the gate inside it. → Phase 5, step 11
Local and world position
The world position is measured from the centre of the scene. The local position (the one in the Inspector) is measured from the parent. A wall piece outside its group uses world space and ends up far away. → Phase 3, step 7
Loop Time
An import setting on an animation clip. When it is ticked, the clip plays again and again (Idle, Walk, Run, Wave). → Phase 4, step 2
Marker
In Gold Rush, an empty object that marks a place: PlayerSpawn, CoinSpot, MonsterSpawn, PowerUpSpot. Later phases add a small script to each one. → Phase 3, step 12
Mask
A UI component that hides everything of its children outside its own shape. The big buttons use it so the gradient and the light sweep stay inside the rounded corners. → Phase 1, step 16
Material
Says how a surface looks: colour, texture, shine, glow. A material is shared: change it, and every object that uses it changes. Gold Rush uses the URP Lit shader. All materials come with the starter package. → Phase 0, step 7
MenuAction
The small script on every menu button. You type a word (play, levels, shop, settings, back, …). On click it plays the click sound and calls GoldRushMenu.Run(word). → Phase 1, step 5
Namespace
A name that groups classes, like a family name for code. Every Gold Rush script starts with namespace GoldRush. Without it, other scripts can't find the class. → Phase 4, step 7
NavMesh / NavMeshAgent
A NavMesh is a map of walkable ground (blue in the Scene view). A NavMeshAgent is a component that finds a path on it and walks there. A NavMeshSurface makes the NavMesh. → Phase 7, step 2
Par time
The target time for a level (Level 1: 40 s). Finishing at or under it earns the second star. → Phase 6, step 2
Phase version
A shorter version of a script that compiles with what you have so far. A later phase says Replace the whole file and gives the bigger version. PlayerMotor and GameManager grow this way. → Phase 4, step 8
Pixels Per Unit Multiplier (PPU)
An Image setting for sliced sprites. It sets how big the round corners are. A pill uses 128 ÷ its height. All layers of one glass piece need the same value. → Phase 1, step 14
PlayerPrefs
Unity's simple key/value storage on the device. Gold Rush stores its whole save under one key. Edit → Clear All PlayerPrefs deletes it. → Phase 1, step 4
Post-processing
Effects on the whole picture after rendering, such as bloom (glow), vignette (dark corners) and tonemapping. Made by the helper EnvironmentSetup. → Phase 1, step 3
Prefab
A saved GameObject you can place many times. Change the prefab, and every copy changes. The level kit is made of prefabs, and you save your own glass UI pieces as prefabs in Prefabs/UI. → Phase 3, step 2
Prefab Mode
Opens a prefab on its own (double-click it) so you can look inside or edit it. A change there updates every copy in every scene. Leave with the < arrow at the top of the Hierarchy. → Phase 5, step 10
Prefab instance and override
An instance is one copy of a prefab in a scene (blue name in the Hierarchy). A change on only that copy is an override (bold in the Inspector). Overrides → Revert All undoes it, Apply All copies it to the prefab. Never Apply All on a kit piece. → Phase 3, step 2, Phase 4, step 15
Raycast
An invisible line shot into the scene that reports what it hits. The camera uses rays to find walls. Monsters use one to check if a wall blocks their view. → Phase 4, step 9
Raycast Target
A tick box on every Image and Text. When it is on, the element catches clicks. Turn it off on decoration (glows, backdrops), or it blocks the buttons behind it. → Phase 1, step 12
Reference resolution
The screen size the UI is designed for (1920 × 1080). The Canvas Scaler (Scale With Screen Size, Match 0.5) scales it to the real screen. → Phase 1, step 12
Resources folder
A Unity folder named exactly Resources. Code can load files from it by name, for example GoldRushAssets, the UI sprites and the icons. Not the same as the course's Resources pack (GoldRush_Export/Resources/). → Phase 0, step 7
Rig (Generic)
The import setting that tells Unity the model has bones it can animate. The Gold Rush characters use Generic. → Phase 4, step 2
Root motion
Letting the animation move the character. It is off in Gold Rush: animations play in place, and code moves the character. → Phase 4, step 12
ScriptableObject
A script that is saved as an asset file, to hold data. GoldRushAssets is one, and so is the day/night palette. → Phase 1, step 7
Seed
The starting number for a random generator. The same seed always gives the same “random” level. The Daily Rush uses today's date as its seed. → Phase 2, step 3
Singleton
A class with exactly one instance that others reach through a static field, like GoldRushMenu.I or GameManager.I. → Phase 1, step 5, Phase 5, step 8
Skybox
The picture all around the scene, behind everything. Gold Rush starts with a sunset sky (GR_SunsetSky). → Phase 3, step 14
Sliced (9-slice)
An Image Type that keeps the corners of a sprite the same size and stretches only the middle. Rounded buttons stay round at any size. → Phase 1, step 14
SmoothDamp
Moves a value toward a target, fast at first and slower at the end. The camera uses it to ease toward the mouse angles. → Phase 4, step 9
Smoothstep
The curve t * t * (3 - 2t): starts slow, speeds up, ends slow. Used for the gate door. → Phase 6, step 3
sqrMagnitude
The squared length of a vector. Comparing squared distances skips a slow square root. Coin and power-up pickups use it. → Phase 5, step 8
Stamina
A 0–1 value that sprinting uses up and rest refills. At 0 the hero is exhausted and must walk. → Phase 4, step 8
State machine
A way to organise behaviour: always exactly one current state, with clear rules for switching. Used by the monsters (Patrol, Alert, Chase, Search, Return, Stunned) and the game (Intro, Playing, Paused, Won, Lost). → Phase 7, step 2
Starter package
The package you import in Phase 0 (GoldRush_Phase00_Project.unitypackage). It has the art, the UI shapes, all materials, the level kit and the models of the coin, gate and power-ups. → Phase 0, step 7
Static
A flag for objects that never move. Unity can draw them faster, and the NavMesh is baked from them. The floor, walls and blocks are under the Static group. The gate must not be static. → Phase 3, step 15
Time.timeScale
How fast game time runs. 0 freezes it (pause), 0.3 is slow motion (when you lose), 1 is normal. → Phase 6, step 8
Toast
A short message that pops up on the HUD and fades away by itself, for example the name of a power-up you picked up. → Phase 9
Trigger (Animator)
An Animator parameter that fires once, such as Hit or Win, to start an action animation. The menu hero waves with the Win trigger. → Phase 4, step 3
Tween
An animation of a value from A to B over time, such as a slide-in or a fade. The menu buttons slide in with Tween. → Phase 1, step 3
Unscaled time
Time.unscaledDeltaTime keeps running even when Time.timeScale is 0. Needed for anything that should move while paused, like the screen fade or the Bob animation. → Phase 1, step 5
URP (Universal Render Pipeline)
The way Unity draws the picture in this project. You get it with the Universal 3D template. Materials must use URP shaders, or they show pink. → Phase 0, step 2
Yaw / pitch
Yaw is turning left and right, pitch is tilting up and down. The camera stores both angles (pitch between 4° and 62°). → Phase 4, step 9

GOLD RUSH · Help

Glossary

Words used in this course, A to Z. After each word you find a link to the step where it is used or explained best.

Active Input Handling
A Player Setting that chooses which input system Unity uses. Gold Rush needs Both: the code uses the classic Input class, and the UI uses the Input System package. Unity restarts when you change it. → Phase 0, step 6
Anchor
The point of the parent a UI element is attached to, from (0, 0) bottom-left to (1, 1) top-right. “Top centre” keeps a button at the top of the screen on every screen size. → Phase 9, step 9
Animator Controller
An asset that decides which animation plays: states, transitions (arrows) and parameters. You build the hero's controller by hand, and one for each monster. → Phase 3, step 4
Any State
A special box in the Animator. An arrow from Any State can start from every state, for example “play Hit when the Hit trigger fires”. → Phase 3, step 7
Bake (NavMesh)
Let Unity calculate the walk map once and save it. Bake again after you move a wall. → Phase 7, step 3
Blend tree
An Animator state that mixes several clips using a number. The Locomotion blend tree mixes Idle (0), Walk (0.5) and Run (1) with the Speed parameter. → Phase 3, step 5
Build Profiles (Scene List)
The window where you choose the platform and the scenes that go into the game. A scene that is not in the list cannot be loaded. MainMenu must be first (index 0). → Phase 9, step 17
CC0
A “no rights reserved” licence. The Quaternius characters are CC0, so you can use them in any project, even commercially. → Phase 0, step 7
CharacterController
A Unity component that moves a capsule with Move() and stops at walls, without physics forces. Used for the hero. → Phase 3, step 9
Checkpoint package
A .unitypackage file with the project as it is at the end of a phase. Import it into a new, empty project if you get lost. → Phase 0, step 1
Collider
An invisible shape that other objects bump into. Walls need one so the hero stops, the camera stops, and the NavMesh leaves a hole. Glowing caps and decoration have none. → Phase 1, step 6
Coroutine
A method that can pause with yield return and continue later, for example to wait a second. The 3-2-1-GO intro and the win/lose sequences are coroutines. → Phase 6, step 8
Dead zone
A small area around the centre of a joystick that counts as “not pushed”. In Gold Rush, stick values under 0.12 count as zero. → Phase 10, step 9
Device Simulator
A Game view mode that shows a phone screen and turns mouse clicks into touches. Use it to test the touch controls. → Phase 10, step 11
Emission
A material setting that makes a surface glow with its own colour, even in the dark. Used for the lights, the gold and the gate strips. → Phase 1, step 4
Event (C#)
A list of methods to call when something happens. DayNight.Changed tells every sun/moon button that the time of day changed. Subscribe with +=, unsubscribe with -=. → Phase 10, step 3
EventSystem
The object that sends clicks and touches to the UI. Without it, no button works. → Phase 9, step 8
Field of view (view cone)
How wide a monster can see. The Slime sees 130° in front, the Mushroom King 200°, the Ghost all around. → Phase 7, step 2
Fog
Makes far-away things fade into a colour. Gold Rush uses Linear fog from 35 to 120 m. → Phase 2, step 14
Grid snapping
Makes the Move tool jump in fixed steps (for example 0.5 m), so blocks line up exactly. → Phase 2, step 5
Has Exit Time
A setting on an Animator arrow: wait until the clip is (almost) finished before you switch. On for the arrows back from Hit and Win, off for arrows that must react at once. → Phase 3, step 7
Ignore Raycast layer
A built-in layer that rays do not hit. The Player is on it, so the camera's wall check and the monsters' view check do not hit the hero himself. → Phase 4, step 9
JSON
A text format for data. The save file is a SaveData object turned into JSON with JsonUtility. → Phase 9, step 3
LateUpdate
Called every frame after all Update() methods. The camera uses it, so it follows a hero that has already moved. → Phase 4, step 4
Lerp
Linear interpolation: Lerp(a, b, t) goes t of the way from a to b. Works for numbers, vectors and colours. The day/night blend is one big Lerp. → Phase 10, step 3
Local and world position
The world position is measured from the centre of the scene. The local position (the one in the Inspector) is measured from the parent. A wall piece outside its group uses world space and ends up far away. → Phase 2, step 7
Loop Time
An import setting on an animation clip. When it is ticked, the clip plays again and again (Idle, Walk, Run). → Phase 3, step 3
Marker
In Gold Rush, an empty object that marks a place: PlayerSpawn, CoinSpot, MonsterSpawn, PowerUpSpot. Later phases add a small script to each one. → Phase 2, step 12
Material
Says how a surface looks: colour, texture, shine, glow. A material is shared: change it, and every object that uses it changes. Gold Rush uses the URP Lit shader. → Phase 1, step 7
Namespace
A name that groups classes, like a folder for code. Every Gold Rush script starts with namespace GoldRush. Without it, other scripts can't find the class. → Phase 3, step 8
NavMesh / NavMeshAgent
A NavMesh is a map of walkable ground (blue in the Scene view). A NavMeshAgent is a component that finds a path on it and walks there. A NavMeshSurface makes the NavMesh. → Phase 7, step 2
Par time
The target time for a level (Level 1: 40 s). Finishing at or under it earns the second star. → Phase 6, step 2
PlayerPrefs
Unity's simple key/value storage on the device. Gold Rush stores its whole save under one key. Edit → Clear All PlayerPrefs deletes it. → Phase 9, step 3
Post-processing
Effects on the whole picture after rendering, such as bloom (glow), vignette (dark corners) and tonemapping. Made by EnvironmentSetup. → Phase 10, step 7
Prefab
A saved GameObject you can place many times. Change the prefab, and every copy changes. → Phase 1, step 2
Prefab Mode
Opens a prefab on its own (double-click it) so you can look inside or edit it. A change there updates every copy in every scene. Leave with the < arrow at the top of the Hierarchy. → Phase 1, step 6
Prefab instance and override
An instance is one copy of a prefab in a scene (blue name in the Hierarchy). A change on only that copy is an override. Overrides → Revert All undoes it, Apply All copies it to the prefab. → Phase 1, step 8
Raycast
An invisible line shot into the scene that reports what it hits. The camera uses rays to find walls. Monsters use one to check if a wall blocks their view. → Phase 4, step 2
Reference resolution
The screen size the UI is designed for (1920 × 1080). The Canvas Scaler scales it to the real screen. → Phase 9, step 8
Resources folder
A Unity folder named exactly Resources. Code can load files from it by name, for example Resources/DayNightPalette. Not the same as the course's Resources pack. → Phase 10, step 6
Rig (Generic)
The import setting that tells Unity the model has bones it can animate. The Gold Rush characters use Generic. → Phase 3, step 2
Root motion
Letting the animation move the character. It is off in Gold Rush: animations play in place, and code moves the character. → Phase 3, step 12
ScriptableObject
A script that is saved as an asset file, to hold data. The day/night palette is one. → Phase 10, step 5
Seed
The starting number for a random generator. The same seed always gives the same “random” level. The Daily Rush uses today's date as its seed. → Phase 9, step 16
Singleton
A class with exactly one instance that others reach through a static field, like GameManager.I. → Phase 5, step 11
Skybox
The picture all around the scene, behind everything. Gold Rush starts with a sunset sky. → Phase 2, step 14
Sliced (9-slice)
An Image Type that keeps the corners of a sprite the same size and stretches only the middle. Rounded buttons stay round at any size. → Phase 9, step 8
SmoothDamp
Moves a value toward a target, fast at first and slower at the end. The camera uses it to ease toward the mouse angles. → Phase 4, step 2
Smoothstep
The curve t * t * (3 - 2t): starts slow, speeds up, ends slow. Used for the gate door. → Phase 6, step 3
sqrMagnitude
The squared length of a vector. Comparing squared distances skips a slow square root. Coin and power-up pickups use it. → Phase 5, step 11
Stamina
A 0–1 value that sprinting uses up and rest refills. At 0 the hero is exhausted and must walk. → Phase 3, step 9
State machine
A way to organise behaviour: always exactly one current state, with clear rules for switching. Used by the monsters (Patrol, Alert, Chase, Search, Return, Stunned) and the game (Intro, Playing, Paused, Won, Lost). → Phase 7, step 2
Starter package
The package you import in Phase 0 (GoldRush_Phase00_Project.unitypackage). It has the art, all materials, the level kit and the models of the coin, gate and power-ups. → Phase 0, step 7
Static
A flag for objects that never move. Unity can draw them faster. The floor, walls and blocks are under the Static group. → Phase 2, step 15
Time.timeScale
How fast game time runs. 0 freezes it (pause), 0.3 is slow motion, 1 is normal. → Phase 6, step 8
Trigger (Animator)
An Animator parameter that fires once, such as Hit or Win, to start an action animation. → Phase 3, step 4
Tween
An animation of a value from A to B over time, such as a pop-in or a fade. The UI helpers use Tween. → Phase 5, step 6
Unscaled time
Time.unscaledDeltaTime keeps running even when Time.timeScale is 0. Needed for anything that should move while paused, like the screen fade. → Phase 9, step 4
URP (Universal Render Pipeline)
The way Unity draws the picture in this project. You get it with the Universal 3D template. Materials must use URP shaders, or they show pink. → Phase 0, step 2
Yaw / pitch
Yaw is turning left and right, pitch is tilting up and down. The camera stores both angles. → Phase 4, step 2

Glossary

Words used in this course, A to Z. The part where a word is explained best is linked after each entry.

Anchor
The point of the parent a UI element is attached to, from (0, 0) bottom-left to (1, 1) top-right. UIKit.At() sets it from code. → Part 4
Animator Controller
An asset that decides which animation plays: states, transitions and parameters. Gold Rush builds its four controllers from code in CharacterSetup.cs. → Part 2
AssetPostprocessor
An Editor script that Unity runs while importing files. CharacterImportRules and UIImportRules set import settings automatically. → Part 2
Blend tree
An Animator state that mixes several clips using a number. Gold Rush's Locomotion blend tree mixes Idle (0), Walk (0.5) and Run (1) with the Speed parameter. → Part 2
CC0
A “no rights reserved” licence. The Quaternius characters are CC0, so they can be used in any project, even commercially. → Part 2
CharacterController
A Unity component that moves a capsule with Move() and stops at walls, without physics forces. Used for the hero. → Part 1
Coroutine
A method that can pause with yield return and continue later, for example to wait a second. The intro countdown and the win/lose sequences are coroutines. → Part 4
Dead zone
A small area around the centre of a joystick that counts as “not pushed”. In Gold Rush it is 12% of the radius. → Part 5
Easing
A curve that changes how an animation speeds up and slows down, such as OutCubic or OutBack. → Part 6
Envelope
How a sound's volume changes over time: attack (fade in), decay and release (fade out). → Part 6
Event (C#)
A list of methods to call when something happens. DayNight.Changed tells every sun/moon button that the time of day changed. Subscribe with +=, unsubscribe with -=. → Part 5
Field of view (view cone)
How wide a monster can see. The slime sees 130° in front, the ghost sees all around. → Part 3
JSON
A text format for data. The save file is a SaveData object turned into JSON with JsonUtility. → Part 4
Juice
Small extra feedback (particles, shake, sounds, bounces) that makes actions feel satisfying. → Part 6
LateUpdate
Called every frame after all Update() methods. Cameras use it so they follow a target that has already moved. → Part 1
Lerp
Linear interpolation: Lerp(a, b, t) goes t of the way from a to b. Works for numbers, vectors and colours. → Part 6
Marker
In Gold Rush, an empty object with a small component (CoinSpot, MonsterSpawn, PowerUpSpot, PlayerSpawn) that tells the game where to create something. → Part 3
NavMesh / NavMeshAgent
A NavMesh is a map of walkable ground. A NavMeshAgent is a component that finds a path on it and walks there. Built at runtime by a NavMeshSurface. → Part 3
Par time
The target time for a level. Finishing at or under it earns the second star. → Part 4
PlayerPrefs
Unity's simple key/value storage on the device. Gold Rush stores its whole save under one key, goldrush_save_v1. → Part 4
Post-processing
Effects applied to the whole picture after rendering, such as bloom (glow), vignette (dark corners) and tonemapping. Set up by EnvironmentSetup. → Part 6
Prefab
A saved GameObject you can place many times. The level building blocks and markers are prefabs in Prefabs/Level/. → Part 1
Raycast
An invisible line shot into the scene that reports what it hits. Monsters use one to check whether a wall blocks their view. → Part 3
Reference resolution
The screen size the UI is designed for (1920 × 1080). The CanvasScaler scales it to the real screen. → Part 5
Root motion
Letting the animation move the character. It is off in Gold Rush: animations play in place, and code moves the character. → Part 2
Seed
The starting number for a random generator. The same seed always gives the same “random” level. The Daily Rush uses today's date as its seed. → Part 1
Singleton
A class with exactly one instance that others can reach through a static field, like GameManager.I. → Part 4
Smoothstep
The curve t * t * (3 - 2t): starts slow, speeds up, ends slow. Used for the day/night blend and the gate door. → Part 6
sqrMagnitude
The squared length of a vector. Comparing squared distances skips a slow square root. → Part 3
Stamina
A 0–1 value that sprinting uses up and rest refills. → Part 1
State machine
A way to organise behaviour: always exactly one current state, with clear rules for switching. Used by the monsters (6 states) and the game (5 states). → Part 3
Time.timeScale
How fast game time runs. 0 freezes it (pause), 0.3 is slow motion, 1 is normal. → Part 4
Trigger (Animator)
An Animator parameter that fires once, such as Hit or Win, to start an action animation. → Part 2
Tween
An animation of a value from A to B over time, such as a pop-in or a fade. → Part 6
Unscaled time
Time.unscaledDeltaTime keeps running even when Time.timeScale is 0. Needed for anything that should move while paused. → Part 4
Yaw / pitch
Yaw is turning left and right, pitch is tilting up and down. The camera stores both angles. → Part 1

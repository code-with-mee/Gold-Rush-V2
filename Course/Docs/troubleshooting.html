GOLD RUSH · Help

Troubleshooting

Something does not work? Find the symptom below. Most problems are fixed by one of the first three tips.

Try these first
  • Run Gold Rush → Setup Project. It rebuilds materials, controllers, scenes and build settings, and is safe to run again.
  • Look at the Console (Window → General → Console). The first red error is usually the real cause.
  • Stop Play mode before you change code, and wait for Unity to finish compiling (the spinner in the bottom-right corner).

Opening the project

Pink objects, or “GoldRushAssets missing” in the Console

The materials or Resources/GoldRushAssets.asset are missing or broken. Run Gold Rush → Setup Project. If objects are still pink, the URP package or the render pipeline asset is missing: check that com.unity.render-pipelines.universal is in the Package Manager and that Assets/Settings/ still has Mobile_RPAsset and PC_RPAsset.

The project does not open, or opens with many errors

Use Unity 6000.6.10f1 or newer. Older versions cannot read the project.

Setup Project did not run by itself

It only runs automatically when one of its key files is missing. Run it from the menu.

Playing

I pressed Play and the hero or camera is missing in the Hierarchy

They only exist in Play mode: the hero, camera, lights, coins, monsters and UI are all created by code. In Edit mode the scenes look almost empty. That is normal.

The mouse cursor disappeared

The game hides and locks it so the mouse can turn the camera. Press Esc (or P) to pause and get it back. Clicking in the Game view locks it again.

My Inspector changes disappeared when I stopped Play

Changes made during Play mode are always undone by Unity, and Player and Main Camera are created by code anyway. Change the value in the script instead.

Every time I press Play, the game plays by itself and takes screenshots

An interrupted smoke test left a file behind. Delete Temp/gr_smoke.run in the project folder.

The joystick does not move in the Editor

On a computer the cursor is locked after the countdown, so it cannot drag the stick. Use the keyboard, or switch the Game view to Simulator (Part 5, step 7).

Input stopped working completely

Check Edit → Project Settings → Player → Other Settings → Active Input Handling. It must be Both (or Input Manager (Old)). The game uses the classic Input class, which stops working on “Input System Package (New)” only.

Levels and monsters

I changed the coins or monsters in Data.cs and nothing changed

Levels 1–4 are saved scenes. Their coins and monsters come from the markers in the scene. Add or remove CoinSpot and MonsterSpawn objects in Level1.unity instead. See Exercise 1.

I added a coin to the scene but it does not appear

Markers must be children of the level root (the object with LevelScene), ideally in Gameplay/Coins. A marker at the top of the Hierarchy is ignored. If a level has no coins at all, the Console says so.

Monsters walk through my new wall

The NavMesh is built from colliders under Static. Put the wall under Static, and make sure it has a Collider. You do not need to bake the NavMesh: it is rebuilt when the level starts.

A monster stands still and never moves

It is not on the NavMesh, for example inside a block or outside the walls. Move its MonsterSpawn onto open floor.

I added a Collider or trigger to a coin and nothing happens

Pickups do not use physics. GameManager measures distances every frame (Part 3, step 2).

Monsters got faster after I took the last coin

That is on purpose: AllCollected() enrages every monster by 10% for the race to the exit.

“Rebuild Level Scenes” erased my level changes

That menu regenerates Level1–Level4 from the generator and overwrites hand edits. Use it only when you want fresh levels, and commit your work first.

Characters and animation

My changes to Hero.controller (or GoldRushAssets) were lost

Setup Project deletes and rebuilds the four controllers and resets the character heights. Make the change in Editor/CharacterSetup.cs, then run Setup Project.

“Clip '…' not found” in the Console

A clip name in CharacterSetup.cs does not match the model. The message lists the names that exist. Note the slime's hit clip is spelled HitRecieve.

I cannot find the Animator on the Player

It is on the child object Player/Model, not on Player.

My new hat does not show

Hats are built in code, in Cosmetics inside CharacterFactory.cs. A new id in Catalog.Hats also needs a case there. Colours only need the catalog line.

Menus, saving and UI

I want to start over with no gold and only Level 1 unlocked

Gold Rush → Reset Save Data.

My change to the save was lost after a restart

Call Save.Persist() after you change Save.Data. A new save field must be a public field of a type JsonUtility can store.

My new UI animation freezes in the pause menu

Pause sets Time.timeScale = 0. Use Time.unscaledDeltaTime or WaitForSecondsRealtime. Tween already uses unscaled time.

A new full-screen panel blocks the joystick

Images catch touches when Raycast Target is on. Turn it off, or put the panel in a CanvasGroup with blocksRaycasts = false.

The Level 5 card overlaps the Daily card

The level-select row is sized for 5 cards. See Exercise 7.

Light, sound and build

No sound

  • Check Mute Audio at the top of the Game view.
  • Check MUSIC and SOUND in the game's Settings or Pause menu. They are saved, so they stay off next time.
  • A typo in a sound id shows [AudioFX] Unknown sound id in the Console.
  • New sounds are made when Play mode starts. Stop and press Play again after adding one.

I changed DayNightPalette.asset and the night colours did not change

In the level scenes, the Day Night Tint component on the level root wins over the palette for the same material. Edit that component instead.

My new light is on during the day

Add a NightLight component to it.

The game turned back to landscape after I set it to portrait

Setup Project sets landscape every time it runs. Change Editor/GoldRushSetup.cs as well.

The iOS build fails with a bundle identifier or signing error

The iOS Bundle Identifier is still the template default. Set your own in Player Settings → Other Settings, plus your Signing Team ID.
